# AppDynamics Apache Web Server Agent Installation Guide

## Overview

This guide provides comprehensive instructions for installing and configuring the AppDynamics Apache Web Server Agent for application performance monitoring (APM).

> **Note:** This repository is intended for reference purposes. Agent configurations and requirements may evolve with new releases. Always verify steps against the [Official AppDynamics Documentation](https://help.splunk.com/en/appdynamics-saas) before proceeding.

## Prerequisites

- Apache2 web server installed on your system
- AppDynamics-compatible Apache agent package downloaded from the [AppDynamics Download Portal](https://accounts.appdynamics.com/downloads)
- Appropriate system permissions to configure Apache and AppDynamics services

## Installation Method / Explanation of Code

**Simple overview of the code:**
This guide covers two installation approaches:

1. **Auto Proxy Mode** - Automatic proxy instrumentation
2. **Manual Proxy Mode** - Manual proxy configuration


**Quick Start Guide:**
- Choose the method that best suits your deployment requirements.
- You can change the logging level for troubleshooting by following the instructions in the MODIFY_LOG_LEVEL.txt file.
